# SEO Template for New/Updated Pages

Use this as a baseline for every new language page.

## Required head tags

```html
<title>Page Title | WSDC Analytics</title>
<meta name="description" content="Short value-focused summary (140-160 chars).">
<link rel="canonical" href="https://wsdc-analytics.github.io/page_en.html">

<meta property="og:type" content="article">
<meta property="og:title" content="Page Title | WSDC Analytics">
<meta property="og:description" content="Same or shorter summary.">
<meta property="og:url" content="https://wsdc-analytics.github.io/page_en.html">

<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="Page Title | WSDC Analytics">
<meta name="twitter:description" content="Short summary.">
```

## Multilingual hints
- Keep per-language canonical URL exact to page variant.
- Keep titles/descriptions semantically equivalent across variants.
- Add/update `sitemap.xml` entries after publishing.

## Content quality checks
- One `h1` per page.
- Meaningful intro paragraph above fold.
- Internal links to related pages.
- No duplicate title/description between unrelated pages.
