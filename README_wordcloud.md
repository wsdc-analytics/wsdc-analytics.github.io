# Генерация облака слов для статьи geo_2025.html

Скрипт создает облако слов из городов и регионов статьи, где размер слова зависит от значимости (количество поинтов).

## Установка зависимостей

```bash
pip install wordcloud pillow numpy
```

или

```bash
pip3 install wordcloud pillow numpy
```

## Использование

### Базовое использование

```bash
python3 generate_wordcloud.py
```

Скрипт:
1. Извлечет данные из `geo_2025.html`
2. Создаст фоновое изображение звездного неба (если его нет)
3. Сгенерирует облако слов и наложит на фон
4. Сохранит результат в `wsdc_geo_wordcloud.png`

### Использование своего фонового изображения

Замените значение переменной `background_image` в скрипте:

```python
background_image = 'your_starfield_image.png'
```

Или передайте путь к изображению как аргумент (если добавите поддержку аргументов).

## Результат

- **Файл**: `wsdc_geo_wordcloud.png`
- **Размер**: 1920x1080 (или по размеру фонового изображения)
- **Формат**: PNG, 300 DPI
- **Количество элементов**: До 60 наиболее значимых городов и регионов

## Настройки

В функции `create_wordcloud_with_background` можно настроить:

- `max_words`: Максимальное количество слов (по умолчанию: 60)
- `min_font_size` / `max_font_size`: Размер шрифта (30-350)
- `colormap`: Цветовая схема (`plasma`, `viridis`, `inferno` и др.)
- `prefer_horizontal`: Соотношение горизонтальных/вертикальных слов (0.6 = 60% горизонтально)
- `relative_scaling`: Относительное масштабирование размеров (0.7 = более выраженные различия)

## Примеры цветовых схем для темного фона

- `plasma`: Фиолетовый-розовый-желтый (по умолчанию)
- `viridis`: Зеленый-желтый
- `inferno`: Черный-красный-желтый
- `magma`: Фиолетовый-розовый-белый
- `cividis`: Синий-желтый
