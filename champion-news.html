How to read this page

This page lists Champion News cards: one card = one threshold crossing for one dancer in one role (leader or follower).

  • Allowed — cumulative All-Stars points reach 150+.
  • Required — All-Stars reach 225+, or Champions reach 10+. If both happen in the same event, the card records the All-Stars pathway. Champions-only Required is possible without a prior Allowed card.
  • Cards are grouped by publication date (when the item was posted here), not only by the event date of the crossing.
  • Open Champion Path for first points, event counts, top events/cities, and continent splits.
  • Use the search box to find a dancer by surname (or full name). This feed is English-only; Telegram Champion News remains a separate editorial channel.

Automated updates after full-parse only create crossings with threshold date on/after 28 Jul 2026. Cards marked as layout probes may appear temporarily while we review the page.
