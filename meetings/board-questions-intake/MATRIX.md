## How to read this matrix

1. **Quote** = Board wording (full ask or the exact bullet/clause we are answering). Do not paraphrase away the original ask.
2. Same quote can appear in **C1** and **C2** when we can only deliver a layer now:
   - **C1 · Depth `full`** — take into work; answer matches the ask with normal registry caveats.
   - **C1 · Depth `partial`** — same quote; we answer **only** for the named scope (usually Scored). Full ask remains open until the C2 twin unlocks.
   - **C2** — same quote; **Enabling** must name the concrete work that unlocks a **full** answer (not a vague “need data”).
3. **C1 sort order (appendices / review):** all `full` first, then `partial`.
4. **IDs** follow Board source numbering; letters / `-E` = splits only. No invented top-level numbers.
