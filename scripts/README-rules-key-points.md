# Методология выявления ключевых изменений правил

## Подход

1. **Сравнение текстов** — извлечь текст из PDF редакции года N и N-1, сравнить (diff)
2. **Жёлтая подсветка** — в новейших версиях (2025+) WSDC выделяет изменения жёлтым; можно использовать при наличии
3. **Формулировка** — 4–5 пунктов в стиле статьи: что изменилось по сравнению с предыдущей редакцией

## Инструменты

- `extract_pdf_highlights.py` — проверка наличия Highlight-аннотаций в PDF (2019 — аннотаций нет)
- `diff_rules_2018_2019.py` — извлечение текста из 2018 PDF в `temp_rules_extract/`
- Текст 2019+ уже в `WSDC Rules Analysis/rules_text/`

## Источники

- **rules_extracted/Правила WSDC/** — исходные PDF (2018, 2019, 2020…)
- **rules_text/** — извлечённый текст (2019+)
- **rules_catalog.csv** — метаданные, для 2025+ есть поле `major_changes`

## Пример для 2019

На основе diff 2018→2019 выделены 5 пунктов:
1. Обязательность раундов с 1 июля 2019
2. Tier по ролям (лидер/фолловер) в одной номинации
3. Trial Event, заявка за 6 месяцев
4. Результаты при закрытии ивента, отчёт Trial за 5 дней
5. Автоматическая пробация при <60 участников
